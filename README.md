# Machinekind — koło naukowe

Repozytorium kontekstowe dla studentów współpracujących z kolektywem
[Machinekind](https://machinekind.ai). Służy jednemu celowi: zebrać w jednym
miejscu, czym jest Machinekind i co trzeba ustalić, żeby założyć wokół niego
koło naukowe. Nie ma tu kodu robota ani jego dokumentacji technicznej; to są
osobne repozytoria i osobny kontekst.

## Jak pracować

Repo jest dokumentacyjne. Zmiany idą przez pull request na `main`. Każdy
dokument ma na górze linię `Status:` (szkic, w uzgodnieniu, przyjęty), żeby
było widać, co jest już ustalone, a co dopiero propozycją. Szczegóły
w [CONTRIBUTING.md](CONTRIBUTING.md).
