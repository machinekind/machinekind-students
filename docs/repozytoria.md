# Repozytoria organizacji machinekind

Status: szkic. Stan na 19 października 2026, tylko repozytoria publiczne.
Repozytoria projektów sprzętowych są wymienione dla orientacji; ich treść nie
wchodzi w zakres tego repo.

| Repozytorium | Czego dotyczy |
| --- | --- |
| `machinekind-students` | to repo: kontekst dla studentów i koła naukowego |
| `website` | strona machinekind.ai (Astro, Cloudflare); repo prywatne |
| `humanoid-lab` | ogólny setup treningu RL dla lokomocji humanoida |
| `humanoid-construction` | dokumentacja budowy humanoida, m.in. konfiguracja silników DAMIAO |
| `so-arm101` | ramię SO-101 |
| `twin` | cyfrowy bliźniak |
| `galaxeo-manipulators` | sterownik SDK do manipulatora Galaxeo Dynamics AXY1 |
| `karta-prelegenta` | generator kart „PRELEGENT” na LinkedIna |
| `w01-tek`, `w01-tek-alien-bazaar` | projekt czworonoga kolektywu; osobny kontekst, nie opisywany tutaj |
| `openproject` | fork OpenProject, narzędzie do zarządzania projektami |
| `.github` | profil organizacji |

Opisy kilku repozytoriów są puste na GitHubie; powyższe streszczenia wynikają
z ich zawartości i należy je uzupełnić, kiedy właściciele dopiszą opisy.
